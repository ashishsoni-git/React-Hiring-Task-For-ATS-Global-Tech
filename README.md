React Shopping Cart  

A simple shopping cart application built with **React**, **Redux Toolkit**, and **React Router**. This project demonstrates state management using Redux, and dynamic cart updates with quantity and total price calculations.  


Features  
- Product listing page  
- Add products to cart  
- Increase/decrease product quantity  
- Remove products from cart  
- Cart data persisted in **localStorage**  
- Navigation using **React Router**  
- Responsive UI  


Tech Stack  
- **React 18**  
- **Redux Toolkit** (State Management)  
- **React Router DOM** (Navigation)  
- **LocalStorage** (Persistence)  
- **CSS/Tailwind/SCSS** (depending on what you used)
